# TattooAI Studio — Frontend

Простий фронтенд (HTML + CSS + JavaScript) для вебплатформи студії
кастомного татуювання TattooAI. Демонструє, що фронтенд, запущений на
іншому порту, отримує дані з API бекенду: показує список усіх ескізів
(`GET /api/v1/designs`).

## Як запустити проєкт

1. Запустіть бекенд (див. README бекенд-репозиторію) і створіть кілька
   ескізів (наприклад, через Postman-колекцію).
2. У теці фронтенду запустіть статичний сервер:

   ```bash
   python -m http.server 5500
   ```

3. Відкрийте http://127.0.0.1:5500 у браузері.

| Частина | Адреса |
|---|---|
| Фронтенд | http://127.0.0.1:5500 (порт 5500) |
| Бекенд (API) | http://127.0.0.1:8000/api/v1 (порт 8000) |

Адреса фронтенду має бути вказана в `CORS_ALLOWED_ORIGINS` у `.env`
бекенду.
